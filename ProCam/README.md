# ProCam — ручная камера для Android (фото + видео)

Сделано под POCO X7 Pro (Android 15), но должно работать на любом Android 10+.

## Что умеет
- Фото: JPEG и RAW (DNG) — если телефон отдаёт RAW сторонним приложениям
- Видео: 4K / 1080p / 720p, 24 / 30 / 60 fps, HEVC или H.264, битрейт 20–150 Мбит/с, звук AAC
- Ручные ISO, выдержка, фокус; переключатель Авто/Ручной для экспозиции и фокуса
- Баланс белого: пресеты от 3000K до 7500K
- Гистограмма, зебра (пересвет), focus peaking (резкость), сетка третей
- Переключение между всеми камерами, которые телефон показывает приложениям
- Файлы сохраняются в галерею: DCIM/ProCam

## Как собрать APK (без Android Studio и без интернета на твоей стороне)
1. Зарегистрируйся на github.com и создай новый репозиторий (New repository).
2. Загрузи в него ВСЁ содержимое этой папки, включая скрытую папку `.github`.
   - Если скрытая папка не загружается: в репозитории нажми Add file → Create new file,
     в имени файла напиши `.github/workflows/build.yml` и вставь туда содержимое файла build.yml из архива.
3. Открой вкладку Actions → Build APK → дождись зелёной галочки (3–6 минут).
   Если сборка не запустилась сама, нажми Run workflow.
4. Зайди в завершённый запуск, внизу в разделе Artifacts скачай `ProCam-apk`.
5. Распакуй архив и установи app-release.apk на телефон (разреши установку из неизвестных источников).
6. При первом запуске дай доступ к камере и микрофону.

## Ограничения
- Кнопка RAW может быть неактивна: многие телефоны Xiaomi скрывают RAW у сторонних приложений.
- Режимы 4K·60 и т.п. показываются только если камера заявляет их поддержку.
- Баланс белого — пресетами, а не плавным ползунком в Кельвинах.
